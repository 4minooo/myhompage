필수 10과목 전체 이수, 선택 7과목 이상 이수 기준으로 자동 판정합니다.

들은 과목을 체크하면 자격 기준을 바로 확인할 수 있습니다.

체크한 과목은 현재 브라우저에 저장됩니다. 선택과목은 7과목을 초과해 체크해도 자격 판정에는 7과목까지만 반영됩니다.

필수 0 / 10 0 / 30학점
선택 0 / 7 0 / 21학점
전체 0 / 17 0 / 51학점

현재 판정

미충족
전체 진행률 0 / 17과목
아직 자격 요건을 충족하지 못했습니다. 필수 10과목, 선택 7과목이 더 필요합니다.

관리 기능

실제 자격증 발급에는 학위 요건, 과목명 인정 여부, 사회복지현장실습 세부 기준, 이수 시점 등이 함께 검토될 수 있습니다. 최종 제출 전에는 학교 또는 자격관리기관 안내를 확인하세요.
